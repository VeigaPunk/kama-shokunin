## Serving defaults (round 92 revision)

Supersedes the round-91 `## Serving timeout and limit thresholds` table row for row (each row names
the T id it replaces; the round-91 rows stay above as the measured round-91 surface). Rule KQ146: a
default is the value **the binary kama reads** uses, so every llama.cpp row with an option is checked
against the pinned `llama-server --help` (b12177 Linux x64, sha256 `ba272ee3…`), and a default no
option prints is bound to the server entry point (`tools/server/`). Ollama and vLLM rows are bound to
the line that reads the environment at run time (vLLM: the `environment_variables` lambda, not the
`TYPE_CHECKING` declaration at `envs.py:26`). Re-check with
`python3 tools/round92-server-defaults.py --repo . --rev <rev> --binary <llama-server>`; a pin bump
can change any value. Context and Gate: `corpus/knowledge/serving-thresholds.md` §Round 92 revision.
