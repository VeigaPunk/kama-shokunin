## Survivors — the finding

### S1. The caps leg is tautological: `canon()` resolves to the head table, not the §Round-42 canonical list (M19, M36, M37)

`tools/round42-selfdesc-reconcile.py:120-126`:

```python
def canon(text):
    best, rows = -1, []
    ...
        m = re.search(r"canonical list as of round\s+(\d+)\*\*", l, re.I)
        if m and int(m.group(1)) > best:
```

The regex is searched anywhere in the line, and the replacement uses strict `>`. `SCORECARD.md:117` — the head Capabilities section's own prose — contains the marker inside backticks: "Mirror of the highest canonical list (``**Capabilities — canonical list as of round 42**`` in §Round 42)." It matches first (best −1 → 42), so `table_rows` parses the head table that follows it. The real §Round-42 table at `SCORECARD.md:2256` then matches with N=42, which is **not** > 42, and is skipped. Direct demonstration (imported the frozen counter, called `canon()` on the pristine file):

```
canon(): best=42 rows=8 names=['sources-registry', 'ollama-offline-evidence-replay', 'live-llamacpp-lifecycle', 'gguf-declared-identity-replay', 'context-capacity-receipt', 'instrument-agreement', 'pin-watch', 'digest-ledger']
canon-marker line 117: Mirror of the highest canonical list (`**Capabilities — canonical list as of round 42**` in §Round 4
canon-marker line 671 / 1952 / 2209 / 2256: (lower or equal rounds, skipped)
```

Consequences, each proven by a committed mutant:

- **M19** (head name `pin-watch` → `pin-watch2`, commit `baced93fbecc4a5285f12156b72c458dc21a7647`): the caps check at `:224` (`sorted(hn) != sorted(names)`) compares the head table against itself, so it cannot fail; `met=True`. The mutant blob verified to contain the edit (`pin-watch2` ×1, `| pin-watch |` ×2 remaining).
- **M36** (§Round-42 canon name edit, commit `1fc2b59e3b60…`): the §Round-42 canonical list is never compared to anything — `met=True`. The retired count fact (`:208`, `len(names) capabilities`) counts head-table rows, not canon rows.
- **M37** (§Round-42 canon first-working edit, commit `ac5d65951425…`): likewise survives; `firsts` derive from the head table.
- **M18/M20** were still killed, but by *other* legs (retired / saturation), not by caps — the kills do not exercise the intended head-vs-canon comparison.

Blast radius: per the preregistration's separability note, the canonical-list row is C2's write. With this tautology, C1's counter cannot detect a desync between the head mirror and the §Round-42 canonical list (the docstring at `:15` says canon is "the highest-numbered … table", so the intent was the real table).

Proposed fix (lane's call — not applied by this seat): anchor `canon()` on a line-start marker, e.g. require `re.match(r"\*\*Capabilities — canonical list as of round (\d+)\*\*", l)` (or skip matches where the marker is inside backticks). Then canon resolves to `SCORECARD.md:2256`, and M19/M36-class mutants die via caps, M37 via caps/saturation. Note the counter/predicates are frozen for round-42 scoring; this is a finding for the closure, not an in-place change.
