usage: kama-live-replay.py [-h] [--receipt RECEIPT] [--work WORK] [--out OUT]
                           [--live LIVE] [--timeout TIMEOUT] [--compare A B]
                           [--selftest] [--scratch SCRATCH]
                           [--witness-dir WITNESS_DIR]
                           [--witness-timeout WITNESS_TIMEOUT]

kama-live-replay.py - re-run a kama-llamacpp-live v4/v5 receipt from its
recorded provenance.

options:
  -h, --help            show this help message and exit
  --receipt RECEIPT
  --work WORK
  --out OUT
  --live LIVE           kama-llamacpp-live.py path
  --timeout TIMEOUT
  --compare A B         compare two receipts with the replay rules (no
                        network)
  --selftest
  --scratch SCRATCH     selftest root (default TMPDIR)
  --witness-dir WITNESS_DIR
                        existing directory passed to the live tool: it writes
                        ready.json {port, pid} there and holds the rerun
                        server until a `release` file appears (round 49)
  --witness-timeout WITNESS_TIMEOUT
                        seconds the live tool waits for `release` (default
                        120)
