Kama owns the identity and current health of a local model endpoint, including reconciling a configured baseURL/model id with the service and model it reaches. That does not transfer ownership of the consumer's credentials, evaluation, route-selection mechanism, or instruction text to kama. (`MINT.md:49-59`; `PROVINCE.md:17-30`; `../AXES.md:15-17`.)

## Contested scope and arbitration

| Contested claim | Recommended owner / boundary |
|---|---|
| Whether the Janitor's 8080 target is safe/correct versus whether request credentials/auth are handled safely. | **Kama** owns the endpoint's listener/service/model identity; **kagi** owns credential and request/auth hygiene. | Endpoint readiness/model identity versus the quality or stability of an eval result. | **Kama** owns current endpoint/liveness and served-model reconciliation; **kengaku** owns task batteries, scoring, calibration, and quality claims. | A model/baseURL/fallback statement in an agent file versus truth about the service. | **Kotoba** owns the instruction/agent surface and its model/fallback wording; **kama** owns independent verification of the target endpoint. `janitor.md`'s no-fallback statement and `distiller.md`'s cascade are declarations, not service-health evidence. (`MINT.md:39,51-59`; `/home/vgpnk/.config/opencode/agents/janitor.md:19-21`; `/home/vgpnk/.config/opencode/agents/distiller.md:5-8`.) |
| Editing or moving the local model systemd listener to address consumer drift. | **Operator** owns host-config changes; **kama** measures and reports the endpoint. Prefer an operator-approved consumer repoint to the current model listener over moving it onto occupied port 8080. The existing disabled 8080 variant must not be enabled as an assumed fix. (`PROVINCE.md:22-26`; `/home/vgpnk/.config/systemd/user/qwen-coder.service:13-22`; `[L1-F1,F2,F8,F10]`.) |

**Falsifiable arbitration rule:** Hold the consumer text, credentials, route table, and evaluation inputs fixed and vary one cause at a time: if changing only the response at a fixed baseURL/port changes service or served-model identity, the finding belongs to kama; if changing only credentials/auth changes it, kagi; if changing only route mapping changes the resolved URL, kumitate; if changing only agent/instruction wording changes it, kotoba; and if changing only tasks/scoring changes it, kengaku. This rule is falsified if the named lane's verdict remains unchanged under its isolated cause while another lane's domain predicate changes. (`../AXES.md:7-17`; `MINT.md:35-42,49-59`.)

## Adjacency rule

If the evidence predicate belongs to another domain—credentials/auth, eval quality, route selection, instruction content, remote web properties, bounty targets, or fleet protocol—kama records only the observed endpoint fact and its evidence, names the owning lane, and hands it off; kama MUST NOT absorb that domain's source edits, authority, credential material, or duplicate evaluation/route work. For host-owned configuration and services, report drift and leave the change to the operator. (`../AXES.md:16-17`; `MINT.md:56-59`; `PROVINCE.md:22-30`.)
