## Findings

**F1 (frozen prereg vs committed battery, MEDIUM — the kill rule is uncheckable as
written).** `preregistration.json:19` states the C1 target as "kill battery: each named
mutant receipt prints met=False (exit 1) with its named leg failing", and
`preregistration.json:44` names `m-ldaudit-writable (code leg)` and
`m-ldaudit-foreign (hostlibs leg)` among the mutants. Both committed receipts print
`met=True` (exit 0): `c1/battery/m-ldaudit-writable.out:2`,
`c1/battery/m-ldaudit-foreign.out:2`. The driver instead classifies the LD_AUDIT vector
as `kind="vector"` and *expects* `met=True` (`run-battery.py:57-67`, `ok = rc == 0 and
met`), and it has no row at all for `m-ldaudit-writable` or `m-extra-in-tree`, whose
receipts are committed (`git -C kama-shokunin ls-tree 8abadfed --
.ufo/waves/round-55/c1/battery/`). Two further mismatches: the prereg's list omits
`m-text-flip` (a live kill) and `m-extra-in-tree` (a void vector). Read literally, the
frozen kill rule is triggered by two of its own named mutants; read as the driver means
it, it is satisfied. The lane cannot edit frozen bytes, so the disposition is an erratum
naming the vector class, and the driver change in `D2/proposed-fix-battery.diff` (fail
on a receipt with no driver row; commit `summary.out`) so the mapping is checkable
without a re-run.

**F2 (criterion wording narrower than the frozen predicate, LOW-MEDIUM).**
`corpus/QUALITY.md:474` (KQ94) admits only when "every executable **file** mapping" is
an archive member / root-owned host file — the exact quantifier K1Cheat used to slip an
anonymous RWX page past the round-53 counter. The round-55 predicate
(`preregistration.json:18`) says "every one of whose **executable mappings**", and the
counter fails anonymous pages (`tools/round54-replay-code-audit.py:499-505`). The
proposal does not edit the criterion (a KQ row is not this seat's to land); it records
the gap and the proposed decision row. Fix for the L1: a KQ94 supersession citing
`corpus/lessons/round-53.md` §Mistakes 6 and round-55's battery.

**F3 (round-55 state observed, not a defect of mine).** `.ufo/waves/round-55/census/`
holds `start.out` only; the round-55 lesson requires an end-of-round census exit 0
(`corpus/lessons/round-55.md` §Mistakes row 3, receipt `census/end.out`). Not present at
review time (`ls .ufo/waves/round-55/census/`).
