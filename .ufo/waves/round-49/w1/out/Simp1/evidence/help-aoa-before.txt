usage: append-only-audit.py [-h] [--repo REPO] [--to TO]
                            [--threshold THRESHOLD] [--contract CONTRACT]
                            [--files FILES] [--json] [--selftest]
                            [--scratch SCRATCH]

append-only-audit.py (v4 definitions, v3 output) - set the lane's declared
append-only files against its git history.

options:
  -h, --help            show this help message and exit
  --repo REPO
  --to TO
  --threshold THRESHOLD
  --contract CONTRACT   contract TSV (default: <to>:registry/append-only-
                        contract.tsv)
  --files FILES         comma list of repo-relative paths (instead of a
                        contract)
  --json
  --selftest
  --scratch SCRATCH     fixture root for --selftest (default $TMPDIR)
