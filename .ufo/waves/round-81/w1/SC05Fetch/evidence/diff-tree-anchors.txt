3654|--name-only
3655|
3656|Show only the name of each changed file in the post-image tree.
3657|The file names are often encoded in UTF-8.
3658|For more information see the discussion about encoding in the git-log[1]
3659|manual page.

3661|--name-status
3662|
3663|Show only the name(s) and status of each changed file. See the description
3664|of the --diff-filter option on what the status letters mean.
3665|Just like --name-only the file names are often encoded in UTF-8.
