- Source: Linux man-pages `F_GET_SEALS(2const)`, https://man7.org/linux/man-pages/man2/F_GET_SEALS.2const.html (linked from fcntl(2), File Sealing; man-pages 6.19, page dated 2026-06-04; accessed 2026-10-27).
- Located quote (9 words): “Seals are a property of an inode.” (§DESCRIPTION, immediately before F_ADD_SEALS). Adjacent sentence: “Thus, all open file descriptors referring to the same inode share the same set of seals.” This explicitly supports that any descriptor open of that same inode observes the same seals, including the server executable image if its `/proc/<pid>/exe` open refers to that inode. The precise `/proc` linkage is an inference from the implementation/observed counter, not a man-page statement.
- Definitions (§DESCRIPTION, “The following seals are available”): `F_SEAL_WRITE` blocks modifications to file contents (but alone does not prevent size changes); `F_SEAL_SHRINK` prevents reducing file size; `F_SEAL_GROW` prevents increasing file size; `F_SEAL_SEAL` prevents further `F_ADD_SEALS` operations, locking the seal set. `F_ADD_SEALS` adds the bitmask to the inode's seal set; `F_GET_SEALS` returns that inode's current seal mask.
