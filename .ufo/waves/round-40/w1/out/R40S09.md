### Counter-compat (routed by R40F05; integrator decision pending)

The frozen C1 counter has five fixture-proven defects (D1–D4 and D3b); as it stands, a
schema-conformant landing cannot yield a `met True` receipt:

- D1 — `teaches` is read at index 7 (= `status` column) at `:63`/`:81`;
  a schema-valid S474 row (marker in `teaches`, index 6) is not credited,
  and only a marker placed in `status` (domain `mined`/`queued`/`rejected`)
  is credited. Every existing superseding row in the corpus puts the marker
  in `teaches` (S031/S040/S056).
- D2 — same off-by-one in the `false_corrections` scan (`:81`): a second
  bogus superseding row written schema-validly is not counted, so
  `false_corrections == 0` can hold while a false correction exists.
- D3 — the `and not amend_corrected` guard (`:84`) is inert on the landed
  shape: once the amendment carries a valid correction section (which
  necessarily contains the wrong digest), the wrong digest elsewhere in the
  file is never counted; the code comment promises behaviour it does not have.
- D3b — the `false_corrections` leg is a one-shot ratchet (R40F05 §4.5):
  the base value `1` comes from the same `:84` clause firing while
  `amend_corrected=0` and the amendment carries the wrong digest; landing the
  `## Correction — round 40` section sets `amend_corrected=1`, making the
  clause unreachable forever (the section's own required content contains the
  wrong digest), so a newly introduced wrong digest (e.g. a later round's
  section) is invisible and `false_corrections == 0` is satisfied by
  construction of the fix, not by the absence of false corrections. This is
  the causal link behind the preregistration kill-rule prose vs base-control
  discrepancy recorded in Grounding.
- D4 — the lesson leg (`:76`) is substring presence, not a correction row:
  prose that merely mentions "R36-D2C" and the digest satisfies it.

These are frozen-counter defects, not predicate text; choosing between
repairing the counter and amending the predicate sentence is the L1's
decision (R40F05 §9); decision scope includes D3b. The counter receipts and
the base controls stay as committed until then.
