## Is the population measurable?

Yes, as a **finite, explicitly scoped regression suite**; not, as currently stated, as a representative/exhaustive population of lane errors. A known-red sample is useful if the only claim is “these named errors are no longer called verdicts.” To measure it honestly, freeze the exact IDs, injection recipes/argv, instrument paths and digests, expected classes, classifier version, timeout, and complete denominator before running either arm. Pin the manifest digest outside the replaceable manifest; prohibit empty, filtered, duplicate, silently skipped, or re-labeled rows. Require both arms to run every row on the same fixtures and require the frozen arm to reproduce its predeclared red vector. Emit every per-cell result and an explicit `error` count. The prompt's fixed instrument-byte revision alone does none of these for the new registry.

Vacuous-win cells to rule out: (a) empty/missing registry or dropping a known-red row; (b) changing `expected_class` after seeing current output; (c) all injected processes fail to launch, yet setup failures are accepted as expected cell errors; (d) every cell is an error and there is no genuine-verdict positive control; (e) errors/timeouts/signals are omitted from the denominator; (f) selftest target text appears before a test-completion marker. [INFERENCE] Each can create `current_misclassified=0` without demonstrating the intended decision boundary unless the manifest, completion/provenance checks, and verdict controls are binding.

## Does error reclassification weaken a detector?

[INFERENCE] Reclassifying the reproduced grid crash would reduce the apparent mutation-kill/rejection count: it would change from the observed false `rejected` to an `error`, so it would no longer earn a kill. That is the correct loss of false-positive credit, not a weaker subject verdict. It becomes a real weakening only if the error becomes `accepted`/exit 0, is silently omitted, or lets the overall measurement pass. Keep `error` distinct and non-passing for the subject; make any missing required observation block a clean measurement. For the citation checker, keep a real emitted `missing`/`mismatch` result as a verdict, but classify a non-null lookup error or absent structured result as could-not-evaluate, even if process exit is 1.
