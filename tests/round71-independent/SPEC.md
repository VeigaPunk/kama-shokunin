# Round71 prospective independent contract

Author and non-author reviewer agreed this contract before any candidate or author test data. Scope is an owned synthetic projection, not OpenAI API or browser conformance, live evidence, service readiness, model identity, generated-output correctness, or a replacement of the historical r31 SSE-presence task.

Invocation: one regular non-symlink local file argument. Wrong arity, missing file, directory or symlink: exit64, empty stdout. Unexpected runtime fault: exit70, never a semantic pass. No sockets, network, subprocesses or external services in candidate.

Read at most65537 bytes and refuse more than65536. Strict UTF-8 outer JSON: reject BOM, duplicate keys anywhere, nonfinite numbers, unpaired surrogates. Exact root keys schema,synthetic,body; schema exactly `kama-chat-stream/v1`, synthetic exactly boolean true, body a string of Unicode scalar values with UTF-8 length <=32768. Extra/missing keys or wrong types invalid. Scalar control characters are not additionally banned. Resource limits and strict decoding are own restrictions, not WHATWG requirements.

Framing: strip at most one leading U+FEFF from body. Read CRLF as one line terminator; lone CR or LF also terminates a line. Only terminated lines are processed, except the final unterminated line is processed as a pending line but cannot trigger blank-line dispatch. Empty terminated line dispatches and resets data and event-type buffers. A line beginning ':' is ignored. Otherwise split at first ':' or use empty value; remove exactly one initial ASCII space from value. Literal lowercase data appends value and LF, event replaces event-type buffer. Other fields ignored. Data-field presence, including empty data, determines whether dispatch occurs; concatenate data and remove final appended LF. Dispatched event type must be absent/empty/message; event-only empty block resets type. Pending EOF data-field presence means incomplete, never dispatch. Unterminated comment/unknown/event/id/retry-only tails are harmless.

Each dispatched payload is either exact `[DONE]` or strict duplicate-free finite JSON. Exact allowed JSON projections:
- chunk: {"choices":[{"index":0,"finish_reason":null or "stop" or "length" or "tool_calls"}]}. Keys exact at each level; index exactly integer0, never boolean. Null chunks may precede final chunks. A non-null reason is final. At most one final; no further chunk after final.
- usage: {"choices":[]}. At most one, only after final and before DONE.
- error: {"error":{"message":nonempty scalar string}}. Keys exact. Error allowed initially or after null chunks; no final or usage before error. After error only one optional DONE allowed.

DONE may appear with no final (incomplete), but only once and no dispatched data may follow. Comments and ignored metadata after DONE are harmless. Every dispatched payload, even following a prior error or DONE, is considered for invalidity. Unknown projection, wrong event type, malformed JSON, empty payload, conflicting order, duplicate final/error/DONE or post-DONE dispatched payload is invalid. No trim or normalization applies to sentinel.

Precedence: any invalid input/dispatch/order => INVALID_OR_INSUFFICIENT exit3; else any pending data => INCOMPLETE exit2; else error => STREAM_ERROR exit2; else final plus DONE => COMPLETE exit0; else INCOMPLETE exit2.
