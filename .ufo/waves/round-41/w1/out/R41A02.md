### F2 — MEDIUM (exploited): citation-format drift is silently unchecked
Predicate: "**every hash, line count, run line and repo path** the row cites re-derives". The legs only see one canonical grammar:
- `HASH_RE` :58 `` `PATH` md5|sha256 `HEX` `` — lowercase hex, exactly 32 or 64. 40-hex git hashes (the exact N2-erratum class), uppercase hex, `sha256:`, backticked algo → no hash fact, no mismatch; the path token still gets a weak existence check (:191-198), so nothing fires.
- `LINES_RE` :59 — requires `(N lines` (plural, parenthesized). `(1 line)` or unparenthesized `N lines` → unchecked.
- `RUN_RE` :60 — literal lowercase `run`, arrow `→`/`->`, `(exit N)`. Capital `Run`, `=>`, `(exit=0)` → unchecked; spaced tokens aren't `path_like` (:101) so they vanish.

Only the `hollow` leg (:199-201) backstops drift, and any single canonical strong fact in the cell defeats it.

## 2. Direct answers

- **Label/leg/vector disagreements**: vector — none (`:53-55` == prereg:16). Formula/CLI — none. Label — the sentence quantifies over "the table"'s rows; the code quantifies over first-occurrence axis labels (F1) in a positionally-windowed row list (F8). Legs — hash/lines/run legs are grammar-contingent (F2), run-exit contingent (F3); the "rows present" leg is label-presence, not row audit (F1); the path leg is existence-only and `path_like`-gated (F9).
- **Legs that cannot fail**: none is structurally dead — every counter fired in some fixture or control. But there is **no leg for extra/duplicate/non-axis rows** (v5) and no leg can fire on drifted-grammar citations (v2b): omission and drift are free behind one canonical strong fact per row.
- **Regex gaps**: HASH :58 (40-hex git hashes, uppercase, `sha256:`, backticked algo); LINES :59 (singular `(1 line)`, unparenthesized counts, `( N lines)` spacing); RUN :60 (capital `Run`, `=>`, `run` without space, `(exit=0)`, exit uncited); PATH :100-103 (`=`/`~`/`*`/`|` tokens exempt; no `\|` unescape at :119).
- **Can "first table after `## Axes`" be fooled?** The anchor cannot be moved undetected (byte-exact :109; shifts fail closed via :207). It *can* be diluted: ≤3 leading junk pipe-lines are silently absorbed (v4), and the audited row-set is first-occurrence-per-label, which is the exploitable surface (v1/v5). Flipping met False→True while the *displayed* table lies is demonstrated via F1, not via table-position games.
