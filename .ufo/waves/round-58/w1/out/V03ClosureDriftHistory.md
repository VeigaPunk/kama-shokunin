Findings (each names what it attacks — C2 predicate/counter, SCORECARD row 18, round-57 spotcheck, lesson `round-57.md:24` calibration-staleness):
1. Structural cause. Each closure spotcheck lands in a commit touching only `corpus/lessons/round-N-verifier-spotcheck.md` (`git show --name-only` on 9c603f39/4229ea1b/2f88b357/3a600d2f/e10b6d39/b89bdab2/2f53614e: one file each) and never `SCORECARD.md`; row 18 is therefore stale from the spotcheck commit until a separate hand edit. Every round 51–57 has a lag window: 29m34s, 41m06s, 48m10s, 9h13m37s, 2h15m15s, 26m08s, 11m41s. The invariant "pointer names maxN" was never true at the commit that created maxN.
2. Drift modes escalated. (a) machine-unequal tokens: `admitted; re-anchored round 52/53`, `rejected; re-anchored round 54` — semantically right, but suffix and truncation (`rejected` drops the –harmed/–honest-stop distinction) break exact comparison (r42 was 0 at 5dacf2c7 and again at 7b74e2f2, both times with the pointer already wrong); (b) skipped round: at 750e76b9 the pointer jumped 53→55 and round-54's spotcheck (rejected-honest-stop) is named as latest outside closure in **no** commit (`sed -n 18p` over every SCORECARD blob → 0 hits); (c) false verdict: 7b74e2f2 wrote `(admitted)` for round 56 while the ledger had recorded `rejected-honest-stop` 25m46s earlier, live for 1h38m38s until bfaea953.
3. Why it survived. At 7b74e2f2 `tools/round42-selfdesc-reconcile.py` printed `r41=0 … mismatches=0 maxN=56 met=True`, exit 0, holding the false token (counter r42=0). At base `git grep -n 'latest outside closure' 2f53614e -- tools/` → 2 hits, both `tools/round54-cited-path-check.py`, which models a pointer re-point as citation class `superseded` (only the replacement path must resolve); `verifier-spotcheck` hits are count/ledger readers, none compares the pointer to maxN or to MANIFEST. The C2 `verdict` and `including` clauses are new coverage, not a restatement of r42.
4. Half-re-derivation. At every commit the stated blob count equals `git ls-tree <rev> corpus/lessons | grep -c verifier-spotcheck` (38,39,40,41,42,43,44); c2c05e30 is the exhibit — count 40→41 while the pointer stayed at 53. The command-output half of the cell was refreshed and the judgement beside it was not.
5. Repair and base calibration both hold. bfaea953 restores N=57/token/incl 57 (pointer counters 0) with r42=1 because the round-58 SCORECARD section is not yet landed; e4891d8a gives r42=0, mismatches=0, met=True, exit 0. Base 2f53614e reproduces the frozen vector exactly (r42=1 stale=1 verdict=1 including=1 mismatches=4, exit 1).

Limits. (i) `including round 54 and 55` at 750e76b9 does name maxN 55 in compound form; the frozen INCL regex reads 54, so that instance's incl=1 is a format mismatch, not an omission. (ii) "MANIFEST truth then" is read from the fleet commit introducing each kama lane_round row (one per round 51–57; rev 941acf70 holds identical verdicts) and ordered by committer time across two repos, not one graph. (iii) History on this path is linear; no rebase/rewrite observed.
