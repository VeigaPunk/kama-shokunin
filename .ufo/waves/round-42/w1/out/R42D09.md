- **Ground Defect in Kama:** In `tools/round41-scorecard-reconcile.py:186-187` and `tools/round41-pinwatch-audit.py:210-211`, exports use `tempfile.mkdtemp` and register cleanup with `atexit.register(shutil.rmtree, export, True)`.

  Output:
  ```

  tools/round41-pinwatch-audit.py:211:     atexit.register(shutil.rmtree, export, True)  # round 42: remove the export (R41A10-10)
  ```
- **Consequence:** `round42-selfdesc-reconcile.py:22` imports `tools/round41-scorecard-reconcile.py` and calls `evaluate()` directly in-process. In any test suite, multi-seed replay, or evaluation harness, multiple calls to `evaluate()` accumulate 253 MB export directories in `/tmp` without releasing them until process termination. If interrupted by `SIGKILL` (hyaku runner timeout or OOM killer), `atexit` never runs, recreating the R41A10-10 disk exhaustion failure.
- **Cross-Lane Sibling Evidence:** In `tameshi` round 42 and `kumitate` round 44, counters enforce deterministic cleanup inside `try ... finally` or `with tempfile.TemporaryDirectory()`, eliminating process-lifetime accumulation.

### 2. Affected Axes
- **operability (8)**: Primary improvement. Eliminates the SIGKILL leak vector and in-process memory/disk accumulation during multi-seed counter runs or swarm audits.
- **calibration (7)**: Protected. Prevents spurious `No space left on device` failures on the C2 counter during parallel seat replays.
- **coverage (9)**: Unaffected.

### 3. Proposed Move
Upgrade the temp directory lifecycle in `tools/round41-scorecard-reconcile.py` and `tools/round41-pinwatch-audit.py` from **process-exit delayed cleanup (`atexit`)** to **function-scoped deterministic cleanup (`try ... finally`)**:

1. In `tools/round41-scorecard-reconcile.py`, wrap the body of `evaluate(repo, tip)`:
   ```python
   def evaluate(repo: str, tip: str) -> tuple[dict, list[str]]:
       export = None
       try:
           # ... existing logic ...
           for cmd, want, code in RUN_RE.findall(ev):
               if export is None:
                   export = tempfile.mkdtemp(prefix="r41c1-")
                   arc = git(repo, "archive", "--format=tar", tip, binary=True)
                   subprocess.run(["tar", "-x", "-C", export], input=arc, check=True)
               ok, why = run_fact(export, cmd, want, code or None)
           # ... remaining logic ...
           return c, details
       finally:
           if export is not None:
               shutil.rmtree(export, ignore_errors=True)
   ```
2. In `tools/round41-pinwatch-audit.py`, wrap `evaluate(repo, tip, seed)`:
   ```python
   def evaluate(repo, tip, seed):
       export = tempfile.mkdtemp(prefix="r41c2-")
       try:
           subprocess.run(["tar", "-x", "-C", export],
                          input=git(repo, "archive", "--format=tar", tip, binary=True),
                          check=True)
           # ... existing evaluation logic ...
           return tip, legs, met, details
       finally:
           shutil.rmtree(export, ignore_errors=True)
   ```

### 4. Risks and Second-Order Effects
- **Runtime Surface:** Clean cutover. `export` is only used internally to evaluate `run_fact` and contract cases; no return value or caller references paths inside `export` after `evaluate()` returns.
- **Contract Surface:** `tools/round42-digest-audit.py:326-342` runs both counters in an isolated `TMPDIR=priv` and checks `len(os.listdir(priv)) == 0`. Function-scoped `finally:` cleanup guarantees that `priv` is empty *even before* the subshell process exits, fully satisfying the `hygiene` leg.
- **Substrate Surface:** If a seat or harness calls `evaluate()` repeatedly in-process (as `round42-selfdesc-reconcile.py` does when imported), disk footprint remains bounded to exactly one active export (~253 MB) rather than $N \times 253\text{ MB}$.
- **Verification Surface:** No risk to existing positive or negative controls.
