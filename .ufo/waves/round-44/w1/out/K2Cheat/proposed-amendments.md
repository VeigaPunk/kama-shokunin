# Proposed C2 counter amendments (PROPOSALS ONLY — nothing here is applied to the lane)

Target: `tools/round44-verdict-ledger-audit.py` (frozen sha256 1933e75b…bd1, verified against
`preregistration.json`). Line numbers are the frozen file's. Each amendment names the shortcut it
refuses and the measured effect on the round-44 draft (92-line C1 draft untouched; C2 draft
`\.ufo/waves/round-44/c2/draft-ledger.tsv`).

## A1 — verdict must sit in the file's verdict grammar, not anywhere after the trend word

Replace `read_line` (lines 91–105) with an adjacency rule:

```python
ADJ = re.compile(r"(expansion|quality|discernment)[^A-Za-z0-9]{0,12}?"
                 r"(unprovable[- ]but[- ]better|unprovable|improved|harmed|unchanged)", re.I)

def read_line(line):
    out = {}
    for m in ADJ.finditer(line):
        out.setdefault(m.group(1).lower(), set()).add(m.group(2).lower().replace(" but ", "-but-"))
    return out
```

Refuses: S4 (negation) and S5 (quotation) because a negated or quoted word is never within 12
non-alphanumerics of the trend word, while every headline form in both corpora is
(`**quality — improved.**`, `| expansion | unchanged |`, `- discernment: improved.`).

Measured: applied to a scratch copy (`amend-audit.py`, receipt `amend-A1-*.out`), the draft has
`valid=186 bad=18` and the met=True steered ledger `valid=191 bad=13`; the headline ledger has one
bad row, the negation row (`25 quality outside` → L193 “quality is not harmed”).  Re-citing that row
to the file's own verdict line (L187 `- **Quality: unchanged.**`) gives
`agree=68 overclaim=2 underclaim=17 other=0 absent=15 met=True`.

## A2 — delete `mixed` from the vocabulary (or require a second cited line)

`mixed` (lines 183–184) is satisfiable by *any* line with two verdict words, whichever clause or
quotation they sit in.  Replace with: add a `line2` header field; `mixed` is valid only when
`line2` is a different, in-range line of the same file whose own A1 verdict for the trend differs.

Refuses: 17 of 189 draft rows whose verdict is a body word/quotation rather than the line's verdict
(6 of the 15 `other` keys are actually agreements, e.g. `43 quality` self L101
`unprovable-but-better` vs outside L96 `unprovable-but-better`).

Measured: removing `mixed` and taking each cited line's A1 verdict moves the draft from
`61/72` to `68/87` (frozen counter, receipt `headline.out`; `67/87` before the L193 correction).

## A3 — the note column must quote the cited verdict phrase

Lines 172–176 check `len(note) >= 20` for *absent* rows only; every other note is unconstrained.
Require every row a `note` that contains a ≥10-character substring of the cited line including the
verdict word (both sides of the ledger).

Refuses: S6b.  Measured: the frozen counter returns `met=True` with all non-absent notes empty
(receipt `empty-notes-bare-axes.out`) and accepts the draft's own `DRAFT automatic last hit` notes.

## A4 — the SCORECARD table must not be derivable from the ledger alone

Mismatch rows (lines 226–229) are compared only on `(round, trend, self, outside)`, so a script can
emit the table from the ledger it is checking.  Require a 5th cell per row holding a ≥15-character
verbatim phrase from each side's cited line, and verify both phrases occur in the respective files
at the cited lines.

Refuses: S1 (draft + generated table).  Measured: the whole section in
`draft-derived-scorecard.diff` (26 rows + summary) was generated by `gen_scorecard.py` from the
ledger in one pass with no file read; `met=True`.

## A5 — state the agreement range, and never count an ambiguous reading as agreement

For each key the rule may accept more than one verdict from the same file (19 key-sides accept ≥3
here).  Recompute and print `steerable=<n>`, and require the summary line to read
`agreement=a/n overclaim=o underclaim=u other=x absent=k steerable=s` with every steerable key
counted as `other` unless it is unambiguous (single accepted reading on each side).

Refuses: S3 (steering).  Measured: agreement is in [58, 77] of 87 comparable keys by citation choice
alone (`ambiguity.txt`); the draft's `absent=15` also removes 15 keys from the comparison
(`n=72`), so the published rate (84.7%) is higher than the honest headline reading (78.2%).

## A6 — the Axes leg must carry a receipt, not a path mention

Line 245 accepts any `## Axes` table row whose first cell contains `calibration` and whose line
contains `registry/verdict-ledger.tsv`.  Require the score cell to be a digit and the row to carry
the counter command plus the exact summary line (or its sha256).

Refuses: S6c.  Measured: `| calibration | - | registry/verdict-ledger.tsv | round 44 |` gives
`axes=1` with an empty score cell (`empty-notes-bare-axes.out`).

## A7 — absent must cite the file's own proof

Lines 172–176 accept `absent` whenever no line *tokenizes* a verdict for the trend.  Require the
note to quote the file's trend heading (or the `git show` proof that the file does not exist), and
report absent per side.
9 of the 15 absent keys are missing outside files (rounds 20–23), 3 are the round-38 self report,
which files its trends as `calibration / coverage / operability` (`# Trends`, fleet
`b0fd7b7f:.ufo/reports/round-38/kama.md:38-42`) — defensible, but it silently removes 3 self keys
from the comparison and the counter never says so.

## A8 (optional) — canonical citation

Require `line` to be the *first* A1-admissible verdict line of the file (or declare `candidates=<n>`
and reject rows where another admissible line would give a different verdict).  Measured: first-hit
vs last-hit give `59` vs `61` agreement on identical bytes; a canonical rule makes any two honest
integrators produce the same figures.
