## Findings

1. **F1 (pin syntax, drafting trap, not a counter defect).** The C1 counter requires the pin as
   ``sha256 `hex``` — `tools/round43-registry-audit.py:78` `SHA_RE = re.compile(r"sha256 `([0-9a-f]{8,64})")`,
   applied at `:165` as `want.startswith(h)`. A row written `sha256 ff5318494c01` (no backticks)
   fails the pins clause and counts as a mismatch even though it is textually the requested token.
   Both delivered rows use backticks. Proposed fix for later row drafts: keep the backticks.
2. **F2 (evidence limit, no exit codes recorded).** The four `.out` receipts hold stdout only; no
   argv, revision or exit status. The Exit-map cells are therefore derived from
   `tools/round35-{coverage,statement}-audit.py:104-134/:151-199`, and the preregistration's
   "exit 1" for the do-nothing controls is an assertion in
   `.ufo/waves/round-35/preregistration.json`, not a byte in an `.out` file. Recorded in notes.md §1-2.
3. **F3 (behaviour worth knowing, existing counter, not fixed).** The coverage counter's
   `git_show` returns `None` on failure (`tools/round35-coverage-audit.py:35-43`) and `load` folds
   that into an empty string (`:83-85`), so a mistyped `--tip` prints `named 0 … met False` and
   exits **1**, indistinguishable from a genuine negative — while the statement counter's
   `git_show` raises and exits **2** (`tools/round35-statement-audit.py:42-50`). A grader assuming
   "2 could not evaluate" for a bad revision would misread the coverage counter. Both rows state
   the real behaviour. Counters are frozen; no change proposed in place — a later round could make
   `load` raise on a failed `git show`.
4. **F4 (observation, not mine).** The shared lane clone's working tree went from clean to two
   untracked files between two `git status --porcelain` calls in this session:
   `corpus/knowledge/runtime-health-surface-processes.md` and `corpus/lessons/round-43.md`. I wrote
   nothing under `/fast/scratch/kama-r43/clone` (all reads via `git show`/`cat-file`/gate `--rev`);
   I cannot attribute the writes from this seat. Noted in notes.md §5.
