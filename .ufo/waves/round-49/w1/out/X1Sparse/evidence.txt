Harness
-------
cell.py     imports the tool copy, wraps hashlib.sha256 with a delegating counter
            (the real hash still does the work) so "bytes hashed" is measured per
            hash object: #1 = archive digest, #2 = member digest; counts are
            checkpointed every 128 MiB so a killed cell still yields a lower bound.
matrix.py   one subprocess per case with a hard timeout; a case that does not
            return is recorded as "no return, killed at N s" plus its checkpoint.
one.py / gen_extras.py   same for the big/malformed fixtures (machine-written).
build_art.py  builds every crafted archive once; before and after consume the
              identical bytes.
