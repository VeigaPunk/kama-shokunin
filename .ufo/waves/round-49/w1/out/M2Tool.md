## Method

1. `git clone --shared <lane> $S/lane`; `git -C $S/lane checkout -q --detach 74558c71…`; local fixture identity `user.name=M2Tool-r49-fixture <m2tool-r49-fixture@invalid>`; `git rev-parse --show-toplevel` asserted equal to the clone before every commit. 2. `base.py` extracted with `git -C $S/lane show 74558c71…:tools/append-only-audit.py` — the blob the counter actually measures (it extracts the tool from `git archive --format=tar <tip>`, not from any worktree).
3. 29 mutants generated by exact one-site string replacement against `base.py`, each asserted present exactly once and each asserted to change the bytes (a first-draft m23 was a silent no-op and was discarded — see "generator corrections"); every mutant `compile()`s. Full definitions + sha256s: `out/M2Tool/mutants-manifest.json`.
4. Stage 1 — `python3 mutants/<id>.py --selftest` for all 29 (exit code + FAIL lines captured in `out/M2Tool/selftests.json`).
5. Stage 2 — every selftest-survivor (16) was copied into the fixture clone as `tools/append-only-audit.py`, committed (`git add` + `git commit`, parent chained from `74558c71…`, each tip's tree = base tree + that one file), and the frozen C2 counter was run against that tip.
