### F2 — the `gate` leg is satisfied by an incidental quoted token (frozen counter, real hole)

`tools/round42-capacity-audit.py:198-206` collects **every** double-quoted token of ≥8 chars on any Gate line naming the S-id and accepts the leg if **any** of them occurs anywhere in the copy. The S479 Gate line also carries inline code `model_info["context_length"] = meta.n_ctx_train;`, whose `"context_length"` is ≥8 chars and occurs in the copy — so a falsified located quote still passes:


The claim is unaffected (the committed quote at `corpus/lessons/round-42.md:21` is exact and located), but the leg's docstring promise — "a double-quoted **located** quote of <= 25 words that occurs … in its committed copy" — is not enforced.

### F3 — the `gate` leg never checks the stated line number (frozen counter, real hole)

Same lines: the quote is only matched against the whole copy. Claiming the S478 quote at a line that does not exist passes:

```
$ # lesson line 20 changed to `Located quote, line 9999:`
entry=1 rows=1 coverage=1 gate=1 census=1 met=True   EXIT=0
```

**Proposed fix for F2+F3 (round 43 — the prereg forbids changing counters after a seat scores, so this is a draft, not an edit):** bind the quote to its stated line and take only the quote introduced by `line N:`:

```python
for l in gl:
    m = re.search(r'line (\d+):\s*"([^"]{8,})"', l)
    if not m or DATE not in l or url not in sec:
        continue
    n, q = int(m.group(1)), m.group(2)
    cl = (ev[sid] or b"").decode(errors="replace").split("\n")
    if 1 <= n <= len(cl) and len(q.split()) <= 25 and norm(q) in norm(cl[n - 1]):
        good = True
```

This closes F2 (inline tokens can no longer satisfy the leg), F3 (the line must contain the quote) and keeps every existing receipt valid, since both committed quotes sit exactly on their stated lines (1627, 2378).
