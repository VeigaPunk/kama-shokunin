## Verified facts (static)
1. **The guard runs before any spawn.** In `run()`, `corpus_problems(cases)` is evaluated before `tempfile.TemporaryDirectory` or `measure_case`. A non-empty `corpus` result only builds `unmeasured_record`s, so no child is created and no temporary root is made. The duplicate check works on the same `strip()`ed `declared` list as the minimum check. A corpus with at least 16 distinct names plus one duplicate now produces the problem text `duplicate case names`. That text appears in `result["error"]` and in every record's `reasons`/`detail` as `"corpus: duplicate case names"`, with `observed_exit: null`.
2. **Child environment.** `child_environment()` passes only PATH (inherited from the runner's `os.environ`, falling back to `/usr/bin:/bin`), HOME and TMPDIR set to the case directory, and `LANG`/`LC_ALL` set to C.UTF-8. The child is started as `sys.executable -I -B`, so all `PYTHON*` variables, user site-packages, and the script directory on `sys.path` are ignored. The runner also sets `shell=False`, `stdin=DEVNULL`, a 30-second timeout, and the default `close_fds=True`.
3. **No network in the code paths.** The classifier imports only argparse, json, os, stat, subprocess, sys, tempfile, and pathlib. There is no socket, urllib, or http import. The runner imports the same kind of stdlib set without any network module.
4. **No grandchildren in classify mode.** The runner always passes `--tags/--ps/--expect`, never `--selftest`. Only `run_selftest` calls `subprocess`, so a wrapped classifier spawns no further processes. The classifier opens its inputs read-only (`os.open(..., O_RDONLY|O_NONBLOCK)`) and writes only to stdout.
5. **Names never become paths.** The runner names case directories by integer index (`root / f"{index:02d}"`). Fixture names containing tabs, quotes, or `../` (for example TabCollision) are only JSON evidence text.
6. **`runpy` keeps the tool's own paths.** `run_path` sets `__file__` to the tool path, so `SCRIPT`/`LANE`/`DEFAULT_CASES` resolve to the real lane. `argparse` reads `sys.argv[1:]`, which is the runner's argv, because `sys.argv[0]` is the wrapper. `main()` re-raises `SystemExit`, so `sys.exit(main())` passes the classifier's exit code through the wrapper.

## Findings

| # | Severity | Exploit / failure path | Smallest remediation (for check.py owner) |
|---|---|---|---|
| H1 | Medium (pending) | **The runner can leave its temp directory outside the harness temp.** `check.py` runs `measure.py` with an inherited environment, and the runner's `TemporaryDirectory(prefix="kama-r14-measure-")` lives under the host TMPDIR. If the runner is killed (outer timeout or signal), its `finally` cleanup never runs and `kama-r14-measure-*` directories (wrapper copies of `tags.json`/`ps.json`) are left in the host `/tmp`. That breaks "temp removed". | Give the runner an explicit environment: `{"PATH": os.environ.get("PATH") or "/usr/bin:/bin", "HOME": <check temp>, "TMPDIR": <check temp>, "LANG": "C.UTF-8", "LC_ALL": "C.UTF-8"}`. Then every runner write sits inside `check.py`'s own `TemporaryDirectory`, which is removed on exit. This also keeps `LD_PRELOAD` and proxy variables out of the runner. |
| H2 | Medium (pending) | **Code injection through the marker path.** The marker path has to be written into the wrapper source, because the runner's child environment carries no custom variables and its cwd is the case directory. If `check.py` builds the source with `f'open("{marker}", "a")'`, a TMPDIR containing `"`, `\`, or a newline breaks the wrapper or injects code. A broken wrapper also produces a false `marker count 0`. | Embed the paths as `repr(str(marker))` and `repr(str(tool))`. The wrapper body should do only: `import runpy`; `with open(MARKER, "a", encoding="utf-8") as f: f.write("x\n")`; `runpy.run_path(TOOL, run_name="__main__")`. No try/except, so `SystemExit` propagates. Create the wrapper with `open(path, "x")` (O_EXCL) inside the check temp. Never put it in the lane tree. |
| H3 | Medium (pending) | **A marker count of 0 can be fabricated.** If the marker is created lazily, "absent" and "read error" both read as 0. A wrapper that dies at interpreter start, or a wrong `--tool` path that the runner resolves to absent (`tool_present: false`), also gives 0, while exit 1 still looks rejected. If `error` is checked by substring only, a "tool absent" run could pass as rejected. | Create an empty marker before invoking the runner. Treat a missing marker as a test failure, and let only `FileNotFoundError`-free reads count. For rejected cases, also require `tool_present is True` and every record `observed_exit is None`. That proves the corpus guard short-circuited, not tool absence. For accepted cases, require `marker_lines == total == len(names)`. |
| H4 | Low | **Provenance mix-up.** The runner's `tool_sha256` hashes the wrapper, not the classifier. Reporting it as classifier provenance would misstate what was measured. | Record `classifier_sha256` from `tools/kama-ollama-evidence.py` separately, and label the runner's `tool_sha256` as the wrapper hash. Do not claim runtime readiness; scope stays offline. |
| H5 | Low | **An empty selection can pass as clean.** An `--only TEST` that matches nothing, a missing matrix, or an empty matrix would give a clean result with total 0. | `--only` with no match must exit 1 with `test_failed` and an error. The contract already requires rejecting a missing or empty matrix. Make `clean` require `total > 0`. |
| H6 | Low | **Orphan or hang on outer timeout.** If `check.py` puts a timeout on the runner, `subprocess.run` kills only the runner. The grandchild has `close_fds` and is bounded by the classifier, so it does not hold `check.py`'s pipes, but it may outlive the runner. | Make the outer timeout larger than `30 * len(names) + slack`, or run with `start_new_session=True` and `os.killpg` on timeout. H1 still guarantees the files are removed. |
| H7 | Info (residual, out of contract) | **Unnamed or whitespace-named fixtures are invisible to the guard.** They are excluded from `declared` and later get the fallback name `case-NN`, which could collide with a literal declared `case-NN`. The same goes for non-string names. The current fixture schema uses only literal strings, so the GuardHarness matrix cannot reach this. | Flag it to the planner only. Per the GuardRepair scope ("No unrelated validation"), do not widen the guard this round. |

## Contract compliance summary
- **Writes:** with H1 and H2 applied, the only writes outside the runner's per-case directories are the wrapper and the marker inside `check.py`'s `TemporaryDirectory`, and all of it is removed when that directory closes.
- **Environment:** the runner's grandchild environment is already minimal (verified, item 2). The runner's own environment is minimal only if H1 is applied.
- **Network:** none in the runner or classifier (verified, item 3). `check.py` must import only stdlib modules (json, os, subprocess, sys, tempfile, pathlib, argparse, hashlib) and no network modules. Still pending until `check.py` lands.
