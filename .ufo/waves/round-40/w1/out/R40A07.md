1. **HIGH — the planned S474 row as conventionally written will not flip `s474_row`.**
   The counter parses rows with `line.split("|")[1:]`, so `s474[7]` is cell 8 of
   the pipe row — the **status** column — not the teaches column (cell 7) the header
   (`| id | source | kind | tier | scope | anchor | teaches | status | opened | recheck | used-by |`)
   and the A03 plan assume. Verified on a fixture git repo (fresh `mktemp -d` clone
   of tip files + counter):
   - Variant A, canonical teaches-cell marker (`supersedes S472 … <correct digest>`
     in cell 7, status `mined`): `s474_row=0` → met False.
   - Variant B, marker in status cell (cell 8): `s474_row=1` → met True.
   The frozen counter is the predicate: for C1 to flip, the S474 row must place the
   `supersedes S472` marker **including the correct digest** in the status cell.
   Census-validate of that variant could not be run here: `tools/sources-census.sh`
   is absent from the lane evidence clone (only round artifacts matching
   `sources-census*` exist under `.ufo/waves/`); that check belongs to E06/E13.
2. **LOW — counter comment/docstring vs. behavior drift.** The docstring/comment
   say the wrong digest "outside its correction section" counts as false, but the
   implementation only counts it when the correction section is absent (line 84).
   With the section present, the pre-existing wrong digest on the S472 line 9 is
   tolerated. Not blocking (the frozen code is the predicate and passes), but the
   round-40 report should not claim the stricter semantics.
3. **INFO — amendment leg passes with the recommended bytes.** End-to-end fixture
