## Round-31 correction record — instrument-agreement isolation and receipt fields

**Append-only correction to the Round-30 capability description** (`SCORECARD.md`, “instrument-agreement” row: “in isolated temp dirs”). Preserve that earlier wording as history; use this correction instead: `instrument-agreement` runs every child process with the same `cwd` and gives each run a fresh `TMPDIR` only. `one_run()` creates a fresh temporary directory, assigns it to the child environment's `TMPDIR`, and calls `subprocess.run(..., cwd=cwd, ...)`; the temporary directory is removed after the run (`tools/instrument-agreement.py:54-69`). Thus the working directory is shared, not isolated.

Receipts record the working-directory string in `cwd`, not a measured revision: the receipt construction includes `cwd` and has no revision/commit field (`tools/instrument-agreement.py:159-163`). The Round-30 receipts A and B both have `cwd` and no revision field. Clarification on exit evidence: receipts do persist each instrument run's exit status as `results[*].exit` (also constructed at lines 67-69), but they do not persist the wrapper's own exit status as a receipt field; the wrapper returns its status separately at lines 169-171. The receipts' top-level fields are `agree`, `command`, `cwd`, `disagree`, `normalize`, `results`, `runs`, `tool`, and `verdict` (`.ufo/waves/round-30/c2/receipt-a.json`, `receipt-b.json`).
