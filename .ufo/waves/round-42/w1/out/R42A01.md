## 6. D1 (defect) — `canon()` anchors on the head mirror sentence; the `caps` leg is self-comparing

- `tools/round42-selfdesc-reconcile.py:120-126`:
  ```
  120  def canon(text):
  124          m = re.search(r"canonical list as of round\s+(\d+)\*\*", l, re.I)
  125          if m and int(m.group(1)) > best:
  126              best, rows = int(m.group(1)), table_rows(lines[i + 1:])
  ```

  The pattern matches an *inline-code* copy of the bold token, and the first strictly-greater match wins.
- The round-42 C1 edit itself introduced that earlier copy: `SCORECARD.md:117` reads ``Mirror of the highest canonical list (`**Capabilities — canonical list as of round 42**` in §Round 42). Registry counts are not restated here: …``. The real canonical list is at `SCORECARD.md:2256` (table rows `2262-2269`). So `canon()` parses the **head** table (rows `SCORECARD.md:121-128`), not the canonical one (rows `:2262-2269`).
- Consequence, measured on the fixture:
  - **M5** — head mirror row renamed to `| digest-ledgerX |` (`SCORECARD.md:128`), commit `f4c39460`: `caps=0 mismatches=0 met=True`, **exit 0**. A head table that no longer names the canonical capability set passes.
  - **M6** — the real canonical row deleted (`SCORECARD.md:2269`), commit `f7e75ef1`: `caps=0 mismatches=0 met=True`, **exit 0**. The canonical table is never read.
  - Receipts: `R42A01/mutant-M5-head-row-renamed.out`, `R42A01/mutant-M6-canonical-row-deleted.out`.
- Status at the claim tip: **latent, not manifest.** The head mirror and the canonical table are byte-identical there (8 rows, all four cells equal — checked programmatically against `SCORECARD.md:121-128` and `:2262-2269`), and an independent check of `PROVINCE.md` against the canonical evidence cells finds 0 missing `tools/`/`registry/` tokens, and `README.md` names all 14 non-dot top-level entries.
