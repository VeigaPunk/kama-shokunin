## Attacks on the counter (all accepted for these rows)

All fragments, checker output and exit codes are in this directory (`frag-attack-*.tsv`, `check-frag-attack-*.txt`).

1. **Release-side range needs no anchor — the load-bearing line can be dropped.** `frag-attack-drop.tsv` keeps the true verdict and pin ranges but sets `release_lines = 518-540,619-640`, i.e. ends one line before `ctx_http.is_ready.store(true);` at **641** — the very line the row's statement rests on. Result: `VALID S037 holds-reworded`, exit 0. Why: only `pin_lines` are tied to the cited numbers (`tools/round46-release-recheck-audit.py:242-252`); a release range is checked solely against the file length (`:239-241`) and for containing `witness_new` (`:276`). A row can therefore certify "order preserved" while excluding the ordering line from the release side.

Result: `VALID S037 holds-reworded`, exit 0. `pairs = list(zip(pr, rr))` at `:254` only checks counts and membership.
