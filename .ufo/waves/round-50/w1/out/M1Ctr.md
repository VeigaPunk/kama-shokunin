# M1Ctr — C1 counter mutation test (round50-replay-bind-audit.py)

**Verdict: the C1 counter is sensitive where its new joins are strict (all strictness mutants killed: 14/36), but most of its individual conjuncts are survivable in isolation on the honest lane — 21 mutants (58%) pass tip+base identically to pristine, several exactly the round-49-cheat mechanisms the counter was built to catch (child_pid join, canary key, sitecustomize marker, listen-inode join, survivor detection). Kill rate is a coverage statement, not a defect: every survivor needs a specific dishonest lane to die, and four of them are already covered by the w1 ablation seats (J1NoEnv, J4Decoy, J2NoPdeathsig).**

## 2. Method

- One `git clone --shared --no-checkout` of the lane into my scratch (single live clone; the counter reads via `git archive`, never the worktree). Both commits verified present (`cat-file -t` → `commit`).
- 36 mutants (`mutants/m*.py`, hashes in `manifest.json`), each = pristine bytes + exact-string replacement(s), generated by `mk_mutants.py` with each pattern required to occur exactly once; every mutant passes `compile()`.
- Per the tasking ("receipt 1 only suffices for bind; the full teardown leg too"), 34 mutants run stacked on the receipt-1 scoping (`RECEIPTS` tuple `(1, 2, 3)` → `(1,)`); the scoping itself is mutant m28, and m29 (`bound>=1`) runs unshortened. Justification: `observe()`/`bind_one` are per-receipt identical, so no listed mutation point is receipt-dependent; m28 (tip `met=True` 10.3 s, base `met=False`) proves the scoping preserves verdicts.
- Driver `drive.py`: parallel runs (10 workers), per-run scratch under `$S/run/<label>`, `--out` receipt, 540 s timeout, then `pkill -9 -f 'M1Ctr/run/<label>'` tree kill so no run can leave my llama-servers behind. Final `pgrep -af 'M1Ctr/run/'`: **none** (a foreign `llama-server` from seat Rev1Base on :49257 existed throughout; never touched).
- Run totals: 74 unique labels + 4 harness reruns = **78 runs; full (3-receipt) runs = 8 < 40**.

## 5. Survivors — coverage findings with proposed killing cases

A survivor is a coverage finding, not license to weaken. Proposed killing cases use only mechanisms the frozen counter already knows:

1. **m21-childpid** (`:442`): join accepts any int. *Kill:* the committed ablation control **J4Decoy** (decoy replay copies the original receipt's `child_pid`) — kills m21 (decoy's stale int passes `isinstance`) while pristine flags `child_pid != observed pid`.
2. **m09-canary-enc** (`:358`): `str in {bytes}` is vacuously False — the canary check is dead code under this mutant. *Kill:* **J1NoEnv** (live tool inherits replay env incl. `KAMA_R50_CANARY`); pristine flags it, m09 cannot see it.
3. **m24-marker-skip / m34-pypath** (`:459`, `:394`): the sitecustomize-marker detector can be disabled by making the planted dir unimportable. *Kill:* **J1NoEnv** again — with the live tool not `-I`, `PYTHONPATH` reaches it and `sitecustomize.py` stamps the marker.
4. **m10-parent-env** (`:355`): parent-environ check droppable. *Kill:* a no-isolation variant where the live tool scrubs its own env but spawns the server with the replay's env (server carries the canary, parent doesn't — inverse of J1NoEnv).
5. **m03-exe-dead** (`:348`): exe digest check droppable. *Kill:* replay bound to a different llama-server build (b11909 receipt + mismatched binary, e.g. `kama-llamacpp-live` invoked against a rebuilt server).
6. **m04-listen-or** (`:352`): join → union makes any LISTEN socket on the port sufficient. *Kill:* a stale pre-bound listener on the claimed port while `ready.json` names a pid that never bound (or bound a different port).
7. **m06-desc-neq** (`:289`): `!= ancestor` returns True after the first hop for any process not a *direct* child — reparented/detached servers pass. *Kill:* a server orphaned to init (double-fork) that still answers the nonce.
8. **m20-released** (`:436`): `released is not None` accepts `released: false` — a rerun that timed out unreleased. *Kill:* a replay whose `--witness-timeout` expires before `release` arrives; receipt `witness.released=false` yet `match` true.
9. **m22-mm-or** (`:447`): receipt `model_mapping` conjuncts become a disjunction — a receipt with correct `sha256` but wrong/absent dev/inode passes. *Kill:* a live tool recording `sha256` from the `--model` path while `dev`/`inode` name a different file (or vice versa) — the round-49 X11ModelSwap-style lane.
10. **m23-post-and** (`:452`): post-release liveness ANDs the two detectors. *Kill:* a server still alive but no longer accepting (half-dead teardown), or still accepting after a pid exit (socket handed to a sibling).
11. **mP-portref** (`:240`): `port_refuses`→True removes the port arm entirely. *Kill:* a replay that exits 0 leaving its server up (same as m23; port is the only remaining detector there).
12. **m37-pidalive** (`:240`): zombie/exited-state inversion makes `pid_alive` always-False — every survivor of the kill tree is invisible (see base evidence: `alive []` while `port ACCEPTS`). *Kill:* pdeathsig-less lane where the orphaned server dies without releasing the port (or a tree with a non-listening survivor) — only `pid_alive` sees it. Related: with `pid_alive` broken the teardown leg still caught base via `port ACCEPTS`; the port arm and the pid arm currently back each other up.
13. **m25-sigterm** (`:509`): SIGKILL→SIGTERM on the invoker survives — Python's default SIGTERM dies, so the whole pdeathsig cascade still fires. *Kill:* an invoker/launcher trapping SIGTERM (a supervising shell, `nohup`-style) — SIGKILL is load-bearing against non-cooperative starters.
14. **m36-starttime** (`:234`) — equivalent: `itrealvalue` (field 18) and `starttime` (field 19) are both constant per process and both change on pid reuse; verdict identical on any input. True equivalent mutant, no killing case needed.
15. **m33-pass-env** (`:117`) — equivalent-for-verdict: `PASS_ENV` only composes the invoker env; nothing in the counter asserts the allow-list (the canary, not the list, is the detector). Even `()` lets downloads and `bash` resolution work (execvp `os.defpath` fallback). Coverage note: the counter cannot detect a *missing* env allow-list — it can only detect its *leak*.
16. **m28/m29** (receipts/bound `:112`,`:587`): receipts 2 and 3 add nothing to the verdict when receipt 1 binds — `RECEIPTS=(1,)` and `bound>=1` both pass the honest lane. *Kill:* a lane where receipt 1 replays but receipts 2/3 are corrupted (different provenance URL now 404s, or different pinned model) — breadth over the three frozen receipts is the only use.
17. **m30-newrow-tip** (`:536`): "new since BASE" is not load-bearing; `rows(tip)` suffices when the row is in fact new. *Kill:* a tip where the S496 row already exists at BASE (pre-dated source row) — mutant accepts, pristine requires the diff.
18. **m32-maps-url** (`:110`): hostname-less needle still matches. *Kill:* a different row containing `proc_pid_maps.5.html` on another host — the man7.org prefix is the unexercised part.
19. **m27-kill-wait** (`:115`): verdict-survives but **control-leg flip** — `KILL_WAIT` must stay under the live child's 120 s `--witness-timeout`, else teardown can never flag a pdeathsig-less lane (proved at base: `after 120.03 s … ok`). KILLED-in-effect; no new case needed (base is the case).
