## Coverage findings (survivors)

1. **M2 — robust survivor (4/4 seeds).** Both checks' fixture grammars generate only regexes `v(\d+)\.(\d+)\.(\d+)` (counter `make_case`, round41-pinwatch-audit.py:142) and `b(\d+)` (:149), plus the selftest's `sem`/`b(\d+)` (pin-watch.py:151,162). A peeled line's ref is `refs/tags/<tag>^{}`, whose name fullmatches neither — so deleting the skip at pin-watch.py:82 changes nothing either check can observe. The counter's own reference skips peeled lines identically (:94). The mutant **is** behavior-bearing — demo (`R41B03/blindspot-demo.out`): with regex `v(\d+).*` and tags `refs/tags/v1.2.3` + `refs/tags/v1.2.3^{}`, pristine prints `newest=v1.2.3` while M2 prints `newest=v1.2.3^{}` (name tie-break at pin-watch.py:119). **Kill recipe:** one fixture case (counter `make_case` arm or selftest case) whose `tag_regex` fullmatches a peeled name, e.g. `v(\d+).*` over an annotated tag. The live leg is also blind with the lane's current registry regexes (semver / `b(\d+)`).
2. **M4 — selftest blind spot.** Exit precedence (pin-watch.py:131) only matters when `behind` coexists with `missing`/`error`; all five selftest cases (:153-171) are single-engine. Demo (`blindspot-demo.out`): pins with engine e1 behind + engine e2 missing → pristine exit 2, M4 exit 1, stdout byte-equal. **Kill recipe:** one mixed selftest case (e.g. behind+missing expecting exit 2). Among the two assigned detectors, only the contract leg holds this invariant, and only via its exit-code comparison on multi-engine cases.

**Scoped reading for C2:** `contract=1` + `selftest pass` does not probe the peeled-ref skip at all (M2), and probes exit precedence only through the counter's exit-code check (M4). The predicate's other behaviors — version ordering, missing status, error status, `newer` comparison — are each killed by both detectors, so the contract invariant is otherwise well-held.
