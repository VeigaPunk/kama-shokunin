# R41B04 — counter fixture blind spots: `tools/round41-pinwatch-audit.py` contract leg

**Verdict: no falsification of C2 — the contract fixture is discriminating (all six deliberate wrong pin-watches killed under the pristine generator; the shipped candidate seed 1072186973 and positive-control seed 41 both exercise every fixture feature), but its power is feature-concentrated and partly probabilistic: each of the five generator features is load-bearing for exactly one defect class (peeled lines doubly covered), the unreadable-engine draw is absent in 5/30 seeds so even a pristine run can skip the error path, and the two weakenings "pins always current" + "no unreadable engine" compose into a fixture under which a pin-watch that never reads any tag list passes the contract leg 30/30.**

## Which generator features are load-bearing

| feature removed | blinded defect class | evidence |
|---|---|---|
| decoys | prefix-match regex looseness (`w2`) | survives 30/30 without decoys; killed 29/30 with them |
| peeled `^{}` lines | line-counting `newer` (`w1`) | survives 30/30 without peeled lines; killed 30/30 with them |
| non-semver `tag_regex` | hardcoded-semver (`w3`) | survives 30/30 semver-only; killed 30/30 pristine |
| unreadable engine | error path (`w4`) | survives 30/30 without it; killed 25/30 pristine |
| non-current pins (behind/missing) | comparison + exit codes (`w5`, `w6`) — **only jointly with the unreadable feature** | see F5/F6 |

Findings:

- **F1 (tasking's example, confirmed):** peeled lines are load-bearing for a pin-watch that counts peeled lines. Kill evidence, pristine seed 41 case 0: reference `engine=fx0e1 pin=v2.3.14 newest=v2.8.7 newer=1 status=behind` vs mutant `…newest=v2.8.7 newer=2 status=behind` — one peeled duplicate of `v2.8.7` inflates `newer` 1→2 (`matrix.json`, w1×pristine×41 fails[0]). Under `no-peeled` the mutant is byte-indistinguishable from the reference: 30/30 pass.
- **F2 (redundant coverage for w1):** `pins always current` independently blinds the same mutant (30/30 survive): with every pin the greatest tag, `newer` is 0 regardless of duplicates. The pristine fixture therefore carries **two independent catches** for the line-counting defect; removing either one alone suffices to blind it.
- **F3 (probabilistic error-path coverage):** the unreadable engine is drawn with p=0.3 per case, so a 6-case contract leg skips the error path entirely in 5/30 seeds (12,13,16,18,28 — exactly the census rows with `unreadable=0`); on those seeds `w4-noerr` passes the leg. The counter prints its seed, so any run's exposure is auditable; both evidence-bearing seeds are safe (candidate seed 1072186973: `unreadable=1`; positive-control seed 41: `unreadable=1`).
- **F4 (probabilistic decoy kill):** decoys are always present, but the rc decoy only flips `newest`/`newer` when its base tag is the engine's newest or above the pin; 1/30 pristine seeds (seed 10) survived with decoys present. Decoys are load-bearing but not deterministically so. (`w2`×`no-peeled` 1/4 in the matrix is a case-rerandomization artifact — the no-peeled patch drops the peel body's `fake_sha` draws, so those cases differ from pristine's — not evidence that peeled lines catch `w2`; `w2` skips `^{}` lines identically to the faithful implementation.)
- **F5 (composition blind spot — sharpest finding):** `pins always current` alone does **not** fully blind the contract leg to an always-current tool: the unreadable engine still exposes it in 25/30 seeds (w5/w6 killed; survivors are exactly seeds 3,5,15,24,26 — the draws with `unreadable=0`). Only the **composed** weakening (`pins-current` + `no-unreadable`) removes every non-`current` row; under it `w5-alwayscurrent` (never reads any tag list) and `w6-exit` pass the contract leg **30/30**. The fixture's power against "always says current" tools rests jointly on behind/missing pins and the unreadable engine.
- **F6 (no dead weight):** every one of the five generator features is load-bearing for at least one defect class; no feature could be dropped without losing a catch. Conversely no single-feature weakening except `no-peeled`/`pins-current` (both → w1) and `no-decoys` (→ w2), `semver-only` (→ w3), `no-unreadable` (→ w4) blurs anything else — the matrix shows all other cells killed.
- **F7 (shipped evidence is clean):** feature census at the candidate receipt's seed 1072186973 (pristine generator): `engines=19 decoy_lines=54 peeled=71 nonsemver=9 unreadable=1 behind=13 missing=2 current=3` — every feature exercised, so the `contract=1` in `.ufo/waves/round-41/c2/candidate.out` was earned on a fully covering draw. Same for positive-control seed 41: `engines=16 decoy_lines=45 peeled=58 nonsemver=4 unreadable=1 behind=7 missing=7 current=1`.
