- **Reject a `/proc/<pid>/maps` dev:inode (or a maps-vs-`stat()` inode match) as the identity of the model bytes.** In `evidence/reject-maps-inode.out` a child maps a file and the parent rewrites that same inode in place: the maps line and `stat(path)` keep dev `103:05` and inode `1220126573`, while the sha256 changes (`53137a63…` → `f8332a00…`). Flip: only a check that hashes the mapped file through its pathname *and* compares dev/inode (what the build does); even that cannot see a rewrite to identical bytes (a stated limit).
- **Reject `pdeathsig` alone as proof of teardown.** Seat S2Gate2's `exp3-pdeathsig.out`: with the signal ignored the child survives the parent's `SIGKILL` (`ignore_survives=True`), and a forked grandchild survives even with the default disposition (`fork_grandchild_survives=True`); only the default-disposition direct child dies.
