**F1 (material, calibration) — candidate receipts name `c8c92db4`, not the assignment's `3d9bd8d7`.**
`c1/candidate.out:1`, `c2/candidate.out:1`, `c3/candidate.out:1` all read `tip=c8c92db4bdf1c64357b995e0fe8d2a4f481fe995`; no receipt anywhere names `3d9bd8d72366e281fab291874524130428ee423d`.

The receipts are consistent with `preregistration.json:69` (`measured_commit_rule`: "measured commit = the integration commit that precedes the receipts commit"), i.e. `c8c92db` is the measured commit and `3d9bd8d` is the receipts commit. But the per-claim `measured_commit` fields are still `null` at the claim tip (`preregistration.json:27,45,63`), so the contract never records which commit was measured.
Proposed fix: in the next commit set `measured_commit` to `c8c92db4bdf1c64357b995e0fe8d2a4f481fe995` in all three claim objects, and have the report say "measured commit `c8c92db`, receipts commit `3d9bd8d`" instead of "measured candidate `3d9bd8d`".

**F2 (material, calibration) — the freeze controls do not measure the freeze commit.**
`controls/freeze.c1.out:1` / `freeze.c2.out:1` / `freeze.c3.out:1` read `tip=b92ad324b52e251e41cea0c3449c3e24028c6119`, which is not `0bfd47abdda1f5ac21a0834654122644fc23e861` and does not exist in the lane clone (`git -C /fast/scratch/kama-r42/clone cat-file -t b92ad324…` → no output). `build_controls.py:58-63` builds it as base + the three copied counters ("freeze stand-in: counters").

**F3 (material, calibration) — `sep-c1-only.c1.out` is stale: it measures the pre-decoupling tree, and at the measured tip the control passes.**

Rebuilt at the measured tip with the builder's own recipe, the control passes: `r41=0 … mismatches=0 met=True`, exit 0 (§6), against the committed `r41=2 … mismatches=2 met=False`, exit 1.
Consequence for the skeleton: the row "`sep-c1-only` → 2 / met=False" must not be presented as evidence that C1 is inseparable from C3 — at the measured commit C1 is separable, and the committed receipt describes `2793eb5`.
Proposed fix: regenerate `sep-c1-only.{c1,c2,c3}.out` with `build_separability.py <clone> 0b606b03… c8c92db… <out>` and commit them; do not edit the existing ones.
