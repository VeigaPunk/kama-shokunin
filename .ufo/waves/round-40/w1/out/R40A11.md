## Can met pass without the authentic files? — No (probed)

- **Untracked/working-tree files do not count.** `git show <tip>:<path>` only reads the
  committed tree. Probe: the r38 scratch repo (HEAD ce41bae6) physically contains spec.json
  and run.json uncommitted; running the counter against it returns
  `spec_exists=0 run_exists=0 … met=False` (exit 1). A copy-in-worktree bypass is impossible.
- **Byte pinning is preimage-resistant.** Passing requires committing blobs whose sha256
  equal the two pins; with the authentic files in hand this is trivially satisfiable (the
  intended fix), and without them it requires a sha256 collision. Positive control: a temp
  fixture repo with the authentic files committed under the exact paths returns
  `spec_exists=1 … met=True` (exit 0).
- **Error paths fail closed:** any git failure or unparsable JSON yields leg 0 → met False.
- **No injectable/ambiguous surface:** paths are constants; tip resolves through git
  (`--tip` full-commit per counting command); blob binary-hashed with no filters (no
  textconv/autocrlf mangling of what is hashed — `git show` returns raw blob bytes).

## Low-severity observations (no false-pass path)

1. **Type leniency in `counts_ok`:** `total == 36` accepts float `36.0`; `len(items) == 36`
   accepts any sized object (dict with 36 keys, string of length 36). Cannot false-pass here
   because the digest pin fixes the exact bytes (authentic files use int `36` / a 36-list).
   Suggest `isinstance(total, int)` and `isinstance(items, list)` for rigor.
2. **Observability:** the receipt line records booleans only — computed digests are not
   printed, so an auditor cannot verify matching hashes from the artifact alone (must rerun).
   Suggest printing short digest suffixes.
3. **Redundancy note:** `counts_ok` adds no independent security beyond the digest pins (any
   blob matching the pins has fixed bytes that already satisfy len=36/total=36); it is
   defense-in-depth/self-documentation, consistent with the predicate text.
4. **Context:** the harness clone HEAD is f327904b (the round-40 freeze commit, child of base
   efe25f96); the do-nothing control `c2-base.out` was reproduced byte-identically by rerunning
   the frozen counter at efe25f96 (exit 1, met False). Untracked round-40 wave scratch
   (`.ufo/waves/round-40/{c1/,w1/plan.err,w1/run.err}`) is present in the clone worktree —
   outside this review.
