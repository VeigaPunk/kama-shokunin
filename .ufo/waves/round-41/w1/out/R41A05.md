## 5. Routed defects found on the way (for the L1; I fixed nothing in the lane)

1. **Counter leaks its run-fact export dir**: `tools/round41-scorecard-reconcile.py:186-188` creates `tempfile.mkdtemp(prefix="r41c1-")` per run-fact-bearing scoring and never removes it — 253 MB per invocation on this repo. Observed at measurement time: 78 orphaned `r41c1-*` dirs, 20 GB, on the 128 GB `/tmp`, which was 100 % full; my first probe attempt died on ENOSPC (`tar: … No space left on device`) and a `git clone` checkout failed with the same. Fix: remove the export in a `finally`, and/or accept a `--workdir`. (I deleted only my own seven builder sandboxes by exact path; the 78 leaks and three foreign `r41-controls-*` sandboxes were left in place — unattributable across seats running the same counter.)
2. **`citation-provenance.py --selftest` (the freshness row's cited instrument) is environment-sensitive**: `check()` runs `git -C <lane> rev-parse --git-dir` with **no** `env=` (`citation-provenance.py:71-75`; the selftest's own `git()` helper at `:136-137` does pass the scrubbed env), so git walk-up discovery applies. This box has `/home/vgpnk/.git` (verified: `git -C /home/vgpnk/R41A05 rev-parse --show-toplevel` → `/home/vgpnk`), so when the selftest's `TemporaryDirectory` (`:129`) lands under `/home`, the `cli-unusable-git` case gets exit 1 + `mismatch` instead of the expected exit 2 + `lane is not a git repository`, the selftest exits 1, and the counter's freshness run fact fails → **tip `met=False` (false negative for the claim)**. Reproduced A/B (`R41A05/env-repro/A.out` exit=1 with `SELFTEST FAIL cli-unusable-git…`, `B.out` exit=0 `selftest: ok (24 cases)`); passes with `TMPDIR=/var/tmp/r41a05` (no repo above). Fix: pass the scrubbed env (or `GIT_CEILING_DIRECTORIES`) to `check()`'s git calls. My first tip batch and first probe attempt were polluted by exactly this + ENOSPC; both were discarded and rerun clean — the clean numbers in §2-§4 are the evidence.
3. Minor: `junk-c1-scoresonly`'s preregistration gloss ("scores corrected, stale evidence kept") is accurate, but as a shortcut control it never exercises `score_bad` (see §3, M2) — the mirror shape (good evidence, wrong score) is the missing arm.
