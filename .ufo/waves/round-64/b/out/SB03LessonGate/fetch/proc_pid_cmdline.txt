7: NAME top
8: /proc/pid/cmdline - command line
9: DESCRIPTION top
10: /proc/pid/cmdline
11: This read-only file holds the complete command line for the
12: process, unless the process is a zombie. In the latter
13: case, there is nothing in this file: that is, a read on
14: this file will return 0 characters.
15: For processes which are still running, the command-line
16: arguments appear in this file in the same layout as they do
17: in process memory: If the process is well-behaved, it is a
18: set of strings separated by null bytes ('\0'), with a
19: further null byte after the last string.
20: This is the common case, but processes have the freedom to
21: override the memory region and break assumptions about the
22: contents or format of the /proc/pid/cmdline file.
23: If, after an execve(2), the process modifies its argv
24: strings, those changes will show up here. This is not the
25: same thing as modifying the argv array.
26: Furthermore, a process may change the memory location that
27: this file refers via prctl(2) operations such as
28: PR_SET_MM_ARG_START.
29: Think of this file as the command line that the process
30: wants you to see.
