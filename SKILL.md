# kama-shokunin

Shonen seed. Develop: decision tables, error patterns, production checklists,
anti-patterns, cited sources — verifiable, not generic.

## Domain

local model serving & endpoint health — local LLM endpoints (llama-server, janitor-pinned
overlays, OMP-resolved baseURLs), endpoint drift, liveness/readiness probes, model-id vs
served-model reconciliation.

## Refuses

model quality/eval (kengaku), credentials & auth flows (kagi), dispatch mechanics
(kumitate), remote surfaces (kake). Boundary: "is the thing at this baseURL the model this
config believes it is, right now" — never "is the model good".
