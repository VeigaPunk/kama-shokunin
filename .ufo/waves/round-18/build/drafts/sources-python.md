## Scope notes and unknowns (do not drop on integration)

- S051 — The page does not say whether the interpreter ever raises a bare `BaseException` instance; the scope statement covers only the subclasses above. The page also says user code should subclass `Exception`, not `BaseException`. Bare `except:` catches everything and is not described by this page. [INFERENCE] `BaseExceptionGroup` wrapping only `Exception` members is an `ExceptionGroup` and is caught; this follows from the quoted constructor sentence.
- S052 — The stable alias page does not state the pytest version it documents, and it has no date beyond the fetch. Host pytest is not installed (`import pytest` → ModuleNotFoundError on 2026-10-20), so no local pytest run confirms the codes. Exit-code values beyond 0, 1, 3, 5 and 6 are not checked here. The code-6 `--max-warnings` entry is not quoted.
- S053 — The www.gnu.org page was not reached; the manual text came from the upstream 1.19 tarball and matches the installed Arch automake 1.19-1 info copy on the same sentence. The statement covers only the default harness with no protocol; TAP and custom test drivers are outside it. The page does not say whether 77 or 99 are reserved across other harnesses.
