479: ### GET `/health`: Returns health check result
480: 
481: This endpoint is public (no API key check). `/v1/health` also works.
482: 
483: **Response format**
484: 
485: - HTTP status code 503
486:   - Body: `{"error": {"code": 503, "message": "Loading model", "type": "unavailable_error"}}`
487:   - Explanation: the model is still being loaded.
488: - HTTP status code 200
489:   - Body: `{"status": "ok" }`
490:   - Explanation: the model is successfully loaded and the server is ready.
491:
