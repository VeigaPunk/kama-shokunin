7: NAME top
8: /proc/pid/environ - initial environment
9: DESCRIPTION top
10: /proc/pid/environ
11: This file contains the initial environment that was set
12: when the currently executing program was started via
13: execve(2). The entries are separated by null bytes ('\0'),
14: and there may be a null byte at the end. Thus, to print
15: out the environment of process 1, you would do:
16: $ cat /proc/1/environ | tr '\000' '\n'
17: If, after an execve(2), the process modifies its
18: environment (e.g., by calling functions such as putenv(3)
19: or modifying the environ(7) variable directly), this file
20: will not reflect those changes.
21: Furthermore, a process may change the memory location that
22: this file refers via prctl(2) operations such as
23: PR_SET_MM_ENV_START.
24: Permission to access this file is governed by a ptrace
25: access mode PTRACE_MODE_READ_FSCREDS check; see ptrace(2).
