## Findings

### 1. Loopback bind is explicit — retained invariant
**Severity:** Medium if weakened. **Exploit path:** a rewrite changing `--host` to a wildcard interface would expose the unauthenticated inference server to reachable peers. **Evidence:** frozen `tools_kama-llamacpp-live.py:1088-1097` — “`'--host', '127.0.0.1'`”; HTTP probes also use `127.0.0.1` at `:392-398`. **Impact:** current launch is loopback-only; do not infer that a control server binding some other address is equivalent. **Smallest remediation:** keep the literal loopback bind and the receipt's exact-argv gate. **One-line L1 check:** `python -c 'import ast,pathlib; f=next(n for n in ast.parse(pathlib.Path("tools/kama-llamacpp-live.py").read_text()).body if isinstance(n,ast.FunctionDef) and n.name=="main"); a=next(n.value for n in ast.walk(f) if isinstance(n,ast.Assign) and any(isinstance(t,ast.Name) and t.id=="server_argv" for t in n.targets)); assert any(getattr(a.elts[i],"value",None)=="--host" and getattr(a.elts[i+1],"value",None)=="127.0.0.1" for i in range(len(a.elts)-1))'`

### 2. Registered-port refusal and `[::1]` parser — retained, fail-closed
**Severity:** Medium if weakened. **Exploit path:** failure to recognize a registered port lets the temporary model server collide with an endpoint consumer. **Evidence:** frozen `:246-271` — “hardcoded pins + every port token the registry TSV expresses”; parser includes IPv4, `localhost`, `[::1]`, `--port`, and `port=` patterns, range-checks 1–65535, and raises on unreadable registry. `:289-300` rejects an explicitly requested registered port before connect/bind. **Impact:** the bracketed IPv6 form is covered; malformed/out-of-range matches are ignored, while false-positive matches only over-refuse. **Smallest remediation:** preserve parsing and the pre-bind refusal; do not pass port 0 to the child. **One-line L1 check:** `python -c 'import importlib.util as u; s=u.spec_from_file_location("m","tools/kama-llamacpp-live.py"); m=u.module_from_spec(s); s.loader.exec_module(m); m.REGISTRY=type("R",(),{"read_text":lambda self,**k:"http://[::1]:34567\n--port=45678\nQwen3-30B"})(); r=m.refused_ports(); assert {34567,45678,8080,34113}<=r and 30 not in r; exec("try:\n m.pick_port(r,34567)\nexcept m.SetupError:\n pass\nelse:\n raise AssertionError")'`

### 3. IPv6 loopback ownership recognition — confirmed false negative
**Severity:** Medium (false rejection, not unsafe acceptance). **Exploit/path:** an otherwise-good child listening on `::1` or IPv4-mapped loopback is not recognized as the port owner; readiness/teardown ownership checks can reject it. **Evidence:** frozen `:331-336` — “`addr_hex.endswith('00000001')`” and a 24-character slice compared with `'0000000000000000FFFF00'`. On this host `/proc/net/tcp6:2` has a live `LISTEN` `::1` row with local address `00000000000000000000000001000000`; it does not end in `00000001`. The mapped-address predicate likewise compares a 24-character slice against a 22-character literal, so it cannot match a 32-character address. **Impact:** the current default `--host 127.0.0.1` avoids this path, but C1's required AF_INET6 `::ffff:127.0.0.1` good-server control will be rejected by the frozen predicate. **Smallest remediation:** decode the kernel's four host-order 32-bit words into an IPv6 address and test loopback/mapped-loopback semantically, rather than suffix/prefix slicing. **One-line L1 check:** synthesize `tcp6` rows for `00000000000000000000000001000000` and `0000000000000000FFFF00000100007F` and assert `_listen_inodes(port)` returns both row inodes; this must pass against the delivered tool.

### 4. Model digest precedes launch — retained hard gate
**Severity:** High if weakened. **Exploit path:** removing/reordering the comparison permits an unpinned or changed model to be served under an expected identity. **Evidence:** frozen `:1008-1023` — “`refusing to launch`” on mismatch; this return precedes port selection/receipt setup at `:1025-1042` and `Popen` at `:1136-1138`. **Impact:** mismatched model bytes stop before child creation (exit 3 in frozen v2). **Smallest remediation:** keep the digest check before all launch-side effects, and keep the gate tied to the supplied digest. **One-line L1 check:** `python -c 'from pathlib import Path; s=Path("tools/kama-llamacpp-live.py").read_text(); assert s.index("if model_sha.lower() != args.model_sha256.lower():") < s.index("subprocess.Popen(server_argv")'`

### 5. Process-group signals require a live child — retained PID-reuse guard
**Severity:** High if weakened. **Exploit path:** signaling a stale PGID after the child exited can hit an unrelated process group after PID/PGID reuse. **Evidence:** frozen `:749-755` — “`poll() reaps a self-exited child`”; `:780-795` guards both TERM and escalated KILL with fresh liveness checks. `Popen(start_new_session=True)` at `:1128-1134` makes the child PID its process-group ID. **Impact:** current normal teardown avoids signaling a dead child; if `poll()` raises, it deliberately fails closed and may leave cleanup unproven rather than risk signaling a stranger. **Smallest remediation:** preserve the fresh `poll()` immediately before each `killpg`; do not replace it with stale receipt state. **One-line L1 check:** mock a process whose `poll()` returns an exit code, run `teardown()` with `os.killpg` mocked, and assert `killpg` was never called.

### 6. Parent-death signal — requested, explicitly best-effort
**Severity:** Medium if represented as guaranteed. **Exploit path:** if the harness parent dies while a child remains alive and `prctl` did not take effect, the server could outlive the harness. **Evidence:** frozen `:365-375` — “`die with SIGKILL if the harness parent dies`” but the `prctl` call is best-effort and exceptions are swallowed; `:1124-1141` records `requested: True, prctl_ok: 'unknown'`. **Impact:** the receipt does not falsely claim a verified prctl result, but this is not a proof that the child will always die with the parent. **Smallest remediation:** preserve the unknown status unless the result is actually observed; do not upgrade it to `true` based only on requesting `prctl`. **One-line L1 check:** patch `ctypes.CDLL` with a fake `prctl`, call `_preexec_pdeathsig()` with the expected parent PID, and assert it receives `(1, SIGKILL, 0, 0, 0)`; also retain the parent-changed `_exit(1)` control.

### 7. Child environment allowlist — retained
**Severity:** Medium if widened. **Exploit path:** inheriting arbitrary caller variables can disclose credentials to the server/probe or let proxy variables redirect probes. **Evidence:** frozen `:82-84` — “`CHILD_ENV_KEYS = ('PATH', 'HOME', 'LANG', 'LC_ALL', 'TMPDIR')`”; `:1103-1104` constructs only those keys and records names, while `:1132-1135` passes that mapping to `Popen`. **Impact:** secrets in other environment variables are not passed or recorded; values of allowed variables are not put in the receipt. **Smallest remediation:** keep the allowlist narrow and pass `child_env`, not `os.environ`. **One-line L1 check:** import the delivered module and assert `set(CHILD_ENV_KEYS)=={'PATH','HOME','LANG','LC_ALL','TMPDIR'}` and the `Popen` call receives `env=child_env`.

### 8. Temporary log handling — cleanup on normal and reducer-failure paths, unlink is best-effort
**Severity:** Low/Medium. **Exploit path:** if unlink fails (e.g. filesystem/permission fault), the temp server log remains; its `OSError` is suppressed. **Evidence:** frozen `:1117-1140` creates a `kama-llamacpp-live-*.log` with `mkstemp`; `:805-826` reduces the tail and unlinks in `finally`, but “`except OSError: pass`” makes deletion failure silent. **Impact:** normal path removes the log even if reduction raises, but the documentation's deletion claim is not absolute. **Smallest remediation:** preserve the `finally` unlink and surface unlink failure as an internal/setup fault (without logging file contents); never claim deletion on failed unlink. **One-line L1 check:** create a temp log, call `teardown(None, port, path)` with `_port_refuses` stubbed true, then assert the path no longer exists.

### 9. Receipt publish path — atomic, caller-selected destination
**Severity:** Low if weakened. **Exploit path:** writing directly to the destination can leave a truncated receipt after interruption; a caller-selected `--out` intentionally chooses the destination and can replace an existing file. **Evidence:** frozen `:973-989` — “`atomic publish: sibling temp file + os.replace`”; stdout is used when `--out` is absent (`:963-964`, `:990-991`). **Impact:** readers see a complete replacement rather than a partially-written receipt; the sibling temp is removed on `OSError`. The path is not sandboxed, so `--out` remains a caller-authorized write target. **Smallest remediation:** retain sibling-temp plus atomic replace; do not silently redirect or broaden the destination. **One-line L1 check:** call `_emit` into a scratch-directory receipt path and assert it parses as the full JSON object and leaves no `.kama-live-*` sibling.

### 10. v3 observability and `BaseException` contract — mandatory non-pass / cleanup boundary
**Severity:** High for missing cleanup/receipt; intentional calibration change for no-loading observation. **Exploit path:** a `KeyboardInterrupt`/`SystemExit` raised inside teardown is not caught by the frozen `except Exception` handlers, so it can unwind the `finally` before the last-chance `killpg`, receipt emission, and signal-handler restore. **Evidence:** frozen `:1241-1249` catches `Exception`, `:1264-1282` catches teardown errors only as `Exception`, and receipt emission is later at `:1385-1419`; `:1258-1259` ignores signals during shutdown. Separately, frozen `DOC` `:136-145` and `:1345-1356` treat no observed 503 as a failed check. **Impact:** v3's required `BaseException` exit-2 behavior must guarantee teardown/backstop and receipt emission; its `loading_envelope_graded: null` exception is weaker evidence than v2's fail, but must remain `not-evaluated`, never pass/exit 0. Do not place a broad `except BaseException: pass` before teardown or catch parser `SystemExit` as a runtime fault. **Smallest remediation:** at post-parse lifecycle/cleanup boundaries record BaseException as internal fault, continue best-effort child cleanup and emit, return exactly 2; keep `Terminated` semantics distinct. Keep null restricted to the loading check and no observed `/v1/models` 503. **One-line L1 checks:** add a teardown-injected `KeyboardInterrupt` control asserting tool exit 2, valid receipt, and no surviving child; add a zero-loading good-server control asserting tool exit 2 and gate exit 3, never pass/exit 0.

## Overall

The frozen v2 tool has clear loopback, registry refusal, pre-launch digest, live-child `killpg`, environment allowlist, and atomic receipt safeguards. The two concrete review findings are the IPv6 `/proc/net/tcp6` false negative and the uncovered BaseException path required by v3. The log unlink is deliberately attempted in `finally`, but its failure is silent. L1 should run the listed regressions against the delivered v3 artifact before treating these invariants as preserved.
