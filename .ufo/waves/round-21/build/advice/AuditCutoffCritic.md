## Smallest safe correction

Preserve the first-add OID and lane tip in an append-only receipt not rewritten with report edits, and read the pin from that captured version—not the latest report body. If a receipt/tip is absent or unresolved (especially after an amended/rebased first-add), return not-evaluable (exit 2), not a timestamp-derived omission verdict. Git commit dates cannot establish cross-repository wall-clock order.
