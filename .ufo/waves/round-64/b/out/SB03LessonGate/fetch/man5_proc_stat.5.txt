7: NAME top
8: /proc/stat - kernel system statistics
9: DESCRIPTION top
10: /proc/stat
11: kernel/system statistics. Varies with architecture.
12: Common entries include:
13: cpu 10132153 290696 3084719 46828483 16683 0 25195 0 175628
14: 0
15: cpu0 1393280 32966 572056 13343292 6130 0 17875 0 23933 0
16: The amount of time, measured in units of USER_HZ
17: (1/100ths of a second on most architectures, use
18: sysconf(_SC_CLK_TCK) to obtain the right value),
19: that the system ("cpu" line) or the specific CPU
20: ("cpuN" line) spent in various states:
21: user (1) Time spent in user mode.
22: nice (2) Time spent in user mode with low priority
23: (nice).
24: system (3) Time spent in system mode.
25: idle (4) Time spent in the idle task. This value
26: should be USER_HZ times the second entry in
27: the /proc/uptime pseudo-file.
28: iowait (since Linux 2.5.41)
29: (5) Time waiting for I/O to complete. This
30: value is not reliable, for the following
31: reasons:
32: • The CPU will not wait for I/O to complete;
33: iowait is the time that a task is waiting
34: for I/O to complete. When a CPU goes into
35: idle state for outstanding task I/O,
36: another task will be scheduled on this
37: CPU.
38: • On a multi-core CPU, the task waiting for
39: I/O to complete is not running on any CPU,
40: so the iowait of each CPU is difficult to
41: calculate.
42: • The value in this field may decrease in
43: certain conditions.
44: irq (since Linux 2.6.0)
45: (6) Time servicing interrupts.
46: softirq (since Linux 2.6.0)
47: (7) Time servicing softirqs.
48: steal (since Linux 2.6.11)
49: (8) Stolen time, which is the time spent in
50: other operating systems when running in a
51: virtualized environment
52: guest (since Linux 2.6.24)
53: (9) Time spent running a virtual CPU for
54: guest operating systems under the control of
55: the Linux kernel.
56: guest_nice (since Linux 2.6.33)
57: (10) Time spent running a niced guest
58: (virtual CPU for guest operating systems
59: under the control of the Linux kernel).
60: page 5741 1808
61: The number of pages the system paged in and the
62: number that were paged out (from disk).
63: swap 1 0
64: The number of swap pages that have been brought in
65: and out.
66: intr 1462898
67: This line shows counts of interrupts serviced since
68: boot time, for each of the possible system
69: interrupts. The first column is the total of all
70: interrupts serviced including unnumbered
71: architecture specific interrupts; each subsequent
72: column is the total for that particular numbered
73: interrupt. Unnumbered interrupts are not shown,
74: only summed into the total.
75: disk_io: (2,0):(31,30,5764,1,2) (3,0):...
76: (major,disk_idx):(noinfo, read_io_ops, blks_read,
77: write_io_ops, blks_written)
78: (Linux 2.4 only)
79: ctxt 115315
80: The number of context switches that the system
81: underwent.
82: btime 769041601
83: boot time, in seconds since the Epoch, 1970-01-01
84: 00:00:00 +0000 (UTC).
85: processes 86031
86: Number of forks since boot.
87: procs_running 6
88: Number of processes in runnable state. (Linux
89: 2.5.45 onward.)
90: procs_blocked 2
91: Number of processes blocked waiting for I/O to
92: complete. (Linux 2.5.45 onward.)
93: softirq 229245889 94 60001584 13619 5175704 2471304 28
94: 51212741 59130143 0 51240672
95: This line shows the number of softirq for all CPUs.
96: The first column is the total of all softirqs and
97: each subsequent column is the total for particular
98: softirq. (Linux 2.6.31 onward.)
