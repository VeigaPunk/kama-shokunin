"At base (efe25f96) every leg is 0 and false_corrections == 0, i.e. met False."

Provenance of `false_corrections=1` at base (blob reads at `efe25f96`):
- `corpus/knowledge/sglang-docs-version-pinning-amendment-2026-10-23.md` contains the wrong
  evidence digest `5585f602f71c4d4f…` exactly once, no `## Correction — round 40` section,
  and the correct digest zero times → the counter's "wrong digest outside correction section"
  branch fires exactly once.
- `corpus/SOURCES.md`: no `S474` row, zero `supersedes S472` rows → no row-level false leg.

So `false_corrections=1` is the legitimate output of the frozen code at base; only the
kill_rule prose is inaccurate. The `met=False` verdict and the flip semantics are unchanged
(`met` requires all three legs AND false_corrections==0). Recommendation: fix the prose in a
later preregistration; no data or counter change needed.
