## Evidence and method

At 2026-10-25, I ran `git ls-remote --tags <URL>` freshly for each upstream. Each command exited 0. I counted distinct `refs/tags/<name>` refs and ignored peeled `^{}` lines; this avoids counting annotated tags twice. Classification is fullmatch against the exact patterns above. These are point-in-time remote inventories, not immutable guarantees.

## Are dropped tags real final releases?

Yes. I queried GitHub's release-by-tag endpoint for representative dropped tags (HTTP success is corroboration, not the only evidence):

- SGLang `v0.5.15.post1`: release exists; `prerelease=false`, `draft=false`, published `2026-07-14T08:43:33Z`. It is a final post-release tag and is newer than the current matching maximum `v0.5.22` only under tag-name order? **No**: its base version is 0.5.15, below 0.5.22. It demonstrates a real final dropped release, but is not newer than this particular pin.
- vLLM `v0.9.0.1`: release exists; `prerelease=false`, `draft=false`, published `2025-05-30T16:11:16Z`. `v0.10.1.1` likewise exists as a final release, published `2025-08-20T21:20:50Z`. These four-part versions exceed current pin `v0.32.0`? **No** under semantic numeric ordering (0.10 < 0.32); they do show the pattern is a real final-release convention, not just prereleases.
- vLLM `v0.8.5.post1`: release exists; `prerelease=false`, `draft=false`, published `2025-05-02T18:03:41Z`.
- llama.cpp `v0.7.0` and `v0.5.0`: releases exist, both `prerelease=false`, `draft=false` (published 2026-10-15 and 2026-09-23 respectively). These are legacy release tags but older than the current b-series pin.

Thus the survey **does not establish that today's lane output is already a false negative for the currently pinned versions**: current matching maxima are SGLang `v0.5.22`, vLLM `v0.32.0`, and llama.cpp `b11887`; the first two equal their pins and llama.cpp is ahead of `b11755`. It **does establish the watch can miss final releases**. A concrete false-negative mechanism is the tool's use of a single exact tag pattern: if a pin is below a later `.postN`, four-part, or legacy release tag, that release is not considered. The present inventory has final nonmatching releases but none of the verified examples ranks above the respective current matching maximum. Do not claim an observed current-pin false negative without demonstrating a dropped final tag newer than that pin.
